# Numpy_Pandas

##  Project Overview

This project demonstrates basic data analysis techniques using **NumPy** and **Pandas**.

The assignment focuses on working with temperature data using NumPy and performing structured data analysis using Pandas Series and DataFrames.

---

##  Objectives

The main objectives of this assignment are:

* Create and manipulate NumPy arrays
* Perform numerical calculations using NumPy
* Apply indexing and slicing techniques
* Create and manipulate Pandas Series
* Use `loc` and `iloc` for data access
* Apply Boolean filtering
* Create and explore Pandas DataFrames
* Perform grouping and aggregation
* Add, modify, and remove rows and columns
* Understand basic data analysis operations

---

# 📊 Project Sections

## 1. NumPy Array Operations

Temperature data for two weeks is analyzed using NumPy.

### Week 1 Temperature Data

```text
[22.5, 25.3, 20.8, 23.4, 26.1, 24.8, 21.9]
```

### Operations Performed

* Created a 1D NumPy array
* Inspected array shape
* Inspected data type
* Checked the number of elements
* Converted Celsius temperatures to Fahrenheit
* Calculated maximum temperature
* Calculated minimum temperature
* Calculated mean temperature
* Applied array indexing
* Applied array slicing
* Extracted first three days
* Extracted weekend temperatures
* Extracted middle three days

### 2D Temperature Array

Temperature data for two weeks was combined into a 2D NumPy array.

The following operations were performed:

* Created a 2D array
* Inspected shape
* Inspected data type
* Checked total number of elements
* Extracted temperatures for each week
* Extracted weekend temperatures for both weeks
